# Omega Factory backlog

## Delivered

- Phase 1: offline First Light factory, Three.js machines and routes, production,
  contracts, upgrades, saves, undo/redo, Logic Lab foundations, Linux desktop build.
- Follow-ups: whole-card mouse/touch dragging and measured route flow rates.
- Phase 2: all five Logic Lab game tiers, implication and three-input challenges,
  NAND-only selector, prerequisite enforcement, next-challenge guidance, and saved
  evidence. These are game milestones, not a certification of real-world expertise.

- Phase 3: plate press, wire mill, frame fabricator, warehouse, and ten persistent
  main/side quests with tracking, prerequisites, unlocks, and once-only rewards.
- Factory management: single Three.js world object, separate interior tab, attached
  wall slots, live production during draft editing, apply/discard and draft history,
  factory levels with 30/20/10-second service outages and automatic restart.

- Things follow-up: shared controls/palette filtered by World or Interior,
  scope-owned ports, extensible enclosure categories, multiple Worlds and Factory
  Things with isolated drafts/progress and collection saves.
- Scope follow-up: World map with external supply/customer routes, catalog placement
  planes, constrained placement, scope-owned boundary controls, compatible external
  routes, and migration of earlier direct routes through new ports.

## Remaining scope

- Connect Omega Factory to ITIOVerse services, including Yai and Kido, once their
  interfaces and desired interactions are established.
- Add learning domains beyond Boolean logic and richer production scenarios.
- Implement the broader Yai compiler, Rust/WASM kernel, and supporting services.
- Add multiplayer and shared factories.
- Add cross-factory transport and arbitrary recursive enclosure behavior.
- Produce and validate Windows/macOS builds with platform signing.
- Prepare Steamworks integration, cloud saves, controller/Steam Deck support,

- Package and validate native mobile builds.

These items describe future scope. No remote deployment or Steam publication has
been performed; service integration and Itionian behavior still need requirements.
